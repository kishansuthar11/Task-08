# Simple Chatbot in Python

This is a basic rule-based chatbot built using Python.  
It uses simple if-elif-else conditions to reply to user input.

---

## Features
- Greets the user
- Responds to simple queries like name, greetings, and help
- Exits when the user types "bye"
